# Jenkins + Docker + Kubernetes Demo Project

This repository is a scaffold to demonstrate a complete CI/CD flow:
- Simple Node.js application
- Dockerfile to build the image
- Jenkinsfile with pipeline: build, test, push, deploy to Kubernetes
- Kubernetes manifests (deployment + service)
- Docker Compose for local testing
- Terraform placeholder for infra automation

## Quick start (local)
1. Build and run with Docker Compose:
   ```bash
   docker compose build
   docker compose up
   ```
2. Open http://localhost:3000

## Jenkins setup notes
- Create a Jenkins pipeline job (multibranch or pipeline) and point to this repo.
- Create credentials in Jenkins:
  - `dockerhub-creds` (username/password) for Docker Hub login
  - `kubeconfig` (file) containing kubeconfig for target cluster
- Jenkins needs docker and kubectl available on the agent (or use docker-in-docker agent).
- Adjust `DOCKER_IMAGE` naming in Jenkinsfile to match your Docker Hub username/repo.

## Kubernetes
Apply manifests:
```bash
kubectl apply -f k8s/
```
Then update images from Jenkins or run:
```bash
kubectl set image deployment/sample-node-app-deployment sample-node-app=your/image:tag
```
